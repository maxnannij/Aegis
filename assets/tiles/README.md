# Tiles

Colocá acá la textura del camino:

- **path_cobblestone.jpg** — la imagen de adoquines (la que pasaste en el chat)

El juego carga `assets/tiles/path_cobblestone.jpg` y la dibuja en **cada** tile de path.

## Cómo subirla

1. Entrá a https://github.com/maxnannij/Aegis
2. Navegá a `assets/tiles/`
3. **Add file → Upload files**
4. Subí el JPG con el nombre exacto: `path_cobblestone.jpg`
5. Commit en `main`

(El conector de GitHub desde Grok solo permite subir texto, no binarios JPG; por eso este paso es manual una sola vez.)
